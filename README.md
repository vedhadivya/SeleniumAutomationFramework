# Selenium Login Automation

## Project Overview

This project automates the login functionality of a web application using Selenium WebDriver. The framework is developed using Java, TestNG, and Maven following the Page Object Model (POM) design pattern.

## Technologies Used

- Java
- Selenium WebDriver
- TestNG
- Maven
- Eclipse IDE
- Git
- GitHub

## Features

- Automates login functionality
- Implements the Page Object Model (POM)
- Uses TestNG for test execution
- Uses Maven for dependency management
